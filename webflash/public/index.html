⚡ Online Web Flasher

Flash firmware SIXWATCS v2.4.0 langsung dari browser tanpa perlu menginstal Python, Arduino IDE, atau driver tambahan.

  • 1
    Hubungkan ke USB: Colokkan board ESP32-C3 SuperMini ke port USB laptop/PC menggunakan kabel data Type-C berkualitas baik.
  • 2
    Klik Tombol Flash: Tekan tombol biru di bawah. Browser akan membuka dialog pilihan port serial.
  • 3
    Pilih Port Serial: Pilih perangkat yang terdeteksi (biasanya USB JTAG/serial debug unit atau COMx / ttyACM0) lalu klik Connect.
  • 4
    Tunggu Selesai (~35 detik): Firmware, bootloader, dan partisi akan dipasang otomatis. Setelah selesai, ESP32-C3 akan reboot dan layar OLED menyala seketika!
⚠️ Browser kamu belum mendukung Web Serial API. Silakan buka halaman ini di Google Chrome, Microsoft Edge, atau Opera (Desktop). ⚠️ Web Serial membutuhkan koneksi aman HTTPS atau localhost.
Target Chip: ESP32-C3 (4MB Flash) • Baudrate: 460,800 bps
💡 Tips Masuk Bootloader (Jika Gagal Connect):
Jika ESP32-C3 tidak terdeteksi atau muncul timeout handshake: Lepas kabel USB, tahan tombol BOOT (GPIO 9) pada board SuperMini, colok kembali kabel USB, lalu lepaskan tombol BOOT. Baru klik tombol install di atas.

Manual Flash via esptool.py:
